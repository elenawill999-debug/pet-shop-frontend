# Pet Shop

Pet Shop is an online store for pet products built with React.

## Features

- Product categories
- All products page
- Discounted products
- Product filtering by price
- Product sorting
- Individual product pages
- Shopping cart
- Product quantity management
- Order form with validation
- Responsive layout
- 404 page

## Technologies

- React
- React Router
- Redux Toolkit
- React Redux
- Axios
- React Hook Form
- CSS

## Backend

This project uses the Pet Shop Backend API.

Backend repository:
https://github.com/strexzy/Pet-Shop-Backend

The backend runs locally on:

http://localhost:3333

## Run the project

Install dependencies:

npm install

Start the frontend:

npm start

The application will run on:

http://localhost:3000
